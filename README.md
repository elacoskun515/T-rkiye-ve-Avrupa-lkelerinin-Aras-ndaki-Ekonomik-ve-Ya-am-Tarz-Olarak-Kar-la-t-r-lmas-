# GDP vs Happiness: Türkiye ve Avrupa Paradoksu (2012-2025)

## Proje Hakkında

Bu proje, Türkiye ve Avrupa ülkelerindeki kişi başına düşen GSYH (GDP) ile yaşam memnuniyeti arasındaki ilişkiyi scrollytelling (kaydırarak anlatı) yöntemiyle incelemektedir.

## Veri Kaynağı

- TÜİK (Türkiye İstatistik Kurumu)

- Eurostat / World Happiness Report

## Proje Yapısı

- `notebooks/analiz.ipynb`: Veri temizleme ve analiz adımları.

- `index.html`: Scrollytelling web sitesi.

- `docs/storyboard.pdf`: Görsel hikaye akış planı.

## Yapay Zekâ Kullanım Beyanı

Bu projenin web tasarımı (HTML/CSS/JS) ve içerik kurgusu aşamalarında yapay zekâ asistanından destek alınmıştır.
